# Security Policy

## Reporting a vulnerability or data exposure

Please **do not open a public issue** for:

- A security vulnerability in our code
- Credentials, API keys or tokens committed by mistake
- **Patient data or other personal data** that appears in any repo

Instead, use the **Report a vulnerability** button on the repo's Security tab, or email **contact.devicedr@gmail.com**.

Please include:

- The repo and file (or commit) affected
- A short description of the issue
- Steps to reproduce it, if relevant

## What happens next

- We aim to acknowledge reports within **3 working days**.
- Exposed data or credentials are removed, and keys are revoked, as a priority.
- We will tell you when the issue is resolved and credit you if you wish.

## Scope

Our repositories are teaching and research material. They are **not medical devices** and must not be used for clinical decisions.
